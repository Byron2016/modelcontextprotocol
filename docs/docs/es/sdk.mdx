## Primeros Pasos

Cada SDK proporciona la misma funcionalidad, pero sigue los modismos y las mejores prácticas de su lenguaje. Todos los SDKs son compatibles con (o soportan):

- Creación de servidores MCP que exponen herramientas, recursos y prompts (indicaciones).
- Construcción de clientes MCP que pueden conectarse a cualquier servidor MCP.
- Protocolos de transporte local y remoto.
- Cumplimiento del protocolo (Protocol compliance) con seguridad de tipos (type safety).

Visita la página del SDK para tu lenguaje elegido para encontrar las instrucciones de instalación, la documentación, y ejemplos.
